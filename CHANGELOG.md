# Changelog

## 1.0.0

Initial release.

- Authentication with a Searcherries personal access token (created on app.searcherries.com/mcp, tab Other clients).
- Triggers: New Project Check (fires when a project completes a new AI visibility check) and New AI Answer (fires when a new AI answer with its judgment is stored; filter to flagged answers for alerts).
- Searches: Find Project, Get Project Summary, Get AI Answers, Get Search Performance, Get Competitors, Get Citations, Get AI Traffic, Get Action Plan.
